SCOPE & LIMITS
This report combines source-anchored findings with a reproducible inventory of UI text call sites, vector resources, and UiIcons call sites. It is a static source audit, not a screenshot/device audit. There is no Android emulator installed, so visual states are represented in the studio simulator rather than claimed as device-verified.
The project has no Browser UI screen; WebBrowserView is the in-app browser view. The subtitle, audio/quality, and settings overlays are sheets; code exposes more than three sheet/dialog states, so they are listed by action rather than miscounted.

MORNYE-GRADE GAP SUMMARY
• Surface hierarchy: app has a dark/AMOLED/light palette, accent presets, radius tokens and grouped settings, but several screens still depend on repeated stroked cards/chips rather than one clear canvas → surface → control hierarchy.
• Density: player actions are split between a 7-control dock and several subtitle rows; Mornye's player layout organizes controls into measured, aligned groups and uses spacious surface-container contrast.
• Typography: the shared scale is strong, but screen code frequently chooses local sizes and bilingual labels; simplify copy and centralize text roles instead of globally shrinking the font.
• Customization: settings expose many raw rows and sliders. Build preview-first tiles for theme/accent/radius/navigation, retaining a collapsible advanced list.
• App icon: current adaptive and monochrome XML assets exist; focus redesign on a single bold, centered cinema-frame/letterform silhouette with safe-zone margins, no fine linework, no text, and identical monochrome geometry.

Canva API note: current export documentation has a design-export-formats endpoint that can report SVG availability and an SVG export job type, but exports can return feature_not_available. The studio offers per-design format checks and manual SVG upload; Canva SVG export is best-effort and cannot be promised for every design.
Production callback note: this repl has no active production deployment. A production URL cannot be supplied until publishing. The studio labels the Replit development callback as development and prefers CANVA_REDIRECT_URI / REPLIT_APP_URL once set.

RECOMMENDED v3.4.4 HANDOFF
1. Replace the scrolling player action pills with an accessible icon dock: CC, audio tracks, aspect, speed, and title search; use a small active indicator and retain spoken labels as accessibility descriptions.
2. Keep the upper HUD title and 3-zone layout; make only the low-frequency options (rotate, lock, PiP, external player, settings) icon controls. Use 44dp touch targets.
3. Collapse subtitle tools into: language / source / sync / style / more. Put AI translation and site search under More; no more than one horizontal chip strip.
4. Home: one receiver state card, one action, one short supporting sentence. Move onboarding steps into a dismissible guided checklist.
5. Settings: preview-first theme, accent, and bar-style tiles; keep the current Simple/Advanced distinction and all existing preferences.
6. Keep changes inside v3.4.x, Java 8, minSdk 26, targetSdk 36, under 5 MB, with the existing layout-parameter and no-AccessibilityService constraints.
